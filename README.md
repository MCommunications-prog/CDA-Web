# CDA Casa del Alfarero · Página web

Página web de la Iglesia de Dios CDA Casa del Alfarero (CDA Orlando Inc), Orlando, Florida.

Publicada con GitHub Pages en https://mcommunications-prog.github.io/CDA-Web/

## Cómo actualizarla
Todo el contenido está en `index.html` (una sola página, sin dependencias). Los datos de la iglesia (horarios, teléfono, redes, ofrendas) se toman solo de fuentes confirmadas por el pastor.

*Transformados en las manos del Alfarero.*
